# PLLI LIVE (experimental)
Unofficial fan project. Subscribe at https://ntfy.sh/plli-live-lab-76c19f804b3e. On iPhone, open Safari, add ntfy to Home Screen, open the installed web app, subscribe to the topic, and grant notifications.
The topic is public and anyone who knows it can publish. Do not treat it as an authenticated production alert feed or share widely until access control is configured.
The monitor uses public Weverse page links and metadata only; it does not download media or log in. It sends only on explicit is_live, and never for VOD or unknown states. Live detection has not been validated against an actual live broadcast.
Workflow manual modes: check (no notification), test (clearly labeled test), send (only explicit live). Schedule runs on the default branch after merging. GitHub schedules can be delayed and are disabled after 60 days of inactivity. No promise of immediate delivery. Review Weverse terms and service limits before public operation.
